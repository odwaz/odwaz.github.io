Wallet API

The public API behind the wallet's gateway. The document is generated by springdoc from the Spring Boot services: every request and response field is described in the code. Try any call below. Calls go to a sandbox that runs in your browser: it follows the services' rules and returns their responses, but nothing reaches a server.

14 operations Bearer JWT after OTP sign-in Idempotent money calls Download the OpenAPI document

1. Sign in

POST /oauth/login with demo@wallet.example and demo-password. The real service texts a one-time code; in the sandbox it is always 123456.

2. Get a token

POST /oauth2/token with grant_type otp, your e-mail as username and otp_code 123456. The token is put into Authorize for you.

3. Move money

Top up, transfer to thandi1760000000001, withdraw. Use a new Idempotency-Key per call: repeating one replays the first result, and reusing it with a different body is refused.
